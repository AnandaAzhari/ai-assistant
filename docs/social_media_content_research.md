# Social Media Content Research (Cold Start Reference)

## Tujuan
Kumpulan pola konten dari sumber publik per jenis usaha, dipakai Social Media Agent sebagai titik awal ide sebelum riwayat internal (Content Learning, lihat `agents/social_media_agent.md`) cukup banyak untuk jadi acuan utama.

## Cara Pakai
Pola di bawah ini adalah **inspirasi umum**, bukan instruksi mengikat dan bukan data spesifik usaha Ananda. Setiap pola wajib disaring dulu lewat Brand Profile usaha terkait (`brand_profiles/`) — tone, larangan tema, dan identitas visual — sebelum dipakai jadi draft. Begitu riwayat internal (draft yang disetujui, koreksi, data performa) sudah cukup banyak per usaha, itu yang jadi acuan utama; referensi di file ini bobotnya turun otomatis secara praktik (dipakai hanya saat riwayat internal belum ada/sedikit).

## Taqi DocuTech (Jasa Dokumen/Print/Akademik)
Pola dari riset promosi jasa print/fotocopy/percetakan dokumen:
- Sudut pesan kecepatan: highlight waktu pengerjaan cepat ("selesai dalam hitungan jam") — relevan untuk mahasiswa/pelajar yang deadline mepet.
- Sudut spesialisasi: sebut jenis layanan spesifik (skripsi, banner, poster, dokumen kantor) daripada "jasa print" generik, supaya menyasar segmen yang tepat.
- Before/after atau contoh hasil cetak untuk menunjukkan kualitas.
- Testimoni pelanggan sebagai bentuk kepercayaan.
- Konten edukatif (bukan cuma promosi): tips format dokumen, panduan sitasi, dsb — sesuai arahan tone edukatif di Brand Profile Taqi DocuTech.

Sumber: [Contoh Iklan Jasa Print - Kiriminaja](https://kiriminaja.com/blog/contoh-iklan-jasa-print)

## Pixiva.ID (Photobooth)
Pola dari riset promosi vendor photobooth:
- Posting hasil foto dari photobooth dengan frame yang estetik dan unik sebagai konten utama.
- Reels/story behind-the-scenes dan momen candid di acara (bukan cuma hasil akhir).
- Strategi hashtag berlapis: lokasi (#photoboothjakarta), jenis acara (#weddingphotobooth), dan umum (#eventindonesia).
- Konten testimoni klien dan "reveal" hasil booth.
- Kolaborasi dengan vendor lain (wedding organizer, event organizer) untuk memperluas jangkauan.

Catatan: karena foto/video berasal dari acara pelanggan, tetap mengikuti larangan di Brand Profile Pixiva.ID soal izin sebelum posting momen pribadi pelanggan (pernikahan/ulang tahun).

Sumber: [Cara Promosi Bisnis Photobooth di Media Sosial - Photolabtech](https://photolabtech.com/blog/cara-promosi-bisnis-photobooth-di-media-sosial/)

## Risol Mamqi (Kuliner Rumahan)
Pola dari riset strategi media sosial bisnis kuliner rumahan:
- Foto produk dengan angle rapi, pencahayaan baik, background sederhana (fokus ke makanan, bukan ramai).
- Caption mencantumkan info praktis: harga, lokasi/cara pemesanan, promo yang sedang berjalan.
- Reels/story behind-the-scenes proses membuat, bukan cuma hasil jadi.
- Highlight menu favorit dan momen makan bareng (keluarga/teman) sesuai tone hangat & menggugah selera.
- Testimoni pelanggan dan update saat ikut acara/bazaar.

Sumber: [6 Strategi Sukses Social Media untuk Bisnis Kuliner - Foodizz](https://foodizz.id/artikel/6-strategi-sukses-social-media-untuk-bisnis-kuliner)

## Batasan Riset Ini
- Pola di atas bersifat umum dari sumber publik tahun 2026, bukan hasil analisis akun sosial media Ananda sendiri.
- Belum mencakup data real seperti jam posting optimal atau performa spesifik kompetitor lokal — bisa ditambahkan belakangan kalau dibutuhkan riset lebih dalam.
- File ini sebaiknya diperbarui berkala seiring tren berubah, bukan dijadikan referensi statis permanen.
